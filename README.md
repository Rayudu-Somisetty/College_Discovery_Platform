# College Discovery Platform (MVP)

This workspace contains a minimal scaffold for the College Discovery Platform MVP.

Folders:

- `backend/` — Node.js + TypeScript + Express mock API
- `frontend/` — Next.js App Router starter pages

Quick start (PowerShell):

```powershell
cd backend
npm install
npm run dev

# in a separate shell
cd frontend
npm install
$env:NEXT_PUBLIC_API_BASE_URL = 'http://localhost:4000'
npm run dev
```
